Run the Sunday planning session. Act as proactive coach - drive it.

1. Read job-search/strategy.md (especially "Failure modes and pivot
   triggers"), last week's file in job-search/weekly/,
   job-search/practice/log.md, job-search/content/ideas.md,
   job-search/content/calendar.md, and the application tracker table in
   job-search/companies/_shortlist.md.
2. Funnel review, numbers first:
   - This week and cumulative: applies, screens, loops, offers
   - Posts published vs cadence; profile views/DMs trend (ask user)
   - Practice sessions done, score trend, weak areas
3. Check every pivot trigger in strategy.md explicitly. Week 4 screen
   trigger, week 6 content trigger, queue below 10, burnout signals
   (how many MVD-only days this week - 3+ means next week gets a
   lighter plan, not a guilt trip). State each trigger: fired or not.
4. List renewal, mandatory: add ~5 fresh companies. Sources: newest
   job-market/data_structured month, companies seen while engaging,
   user suggestions. Tier them, gate early-stage (2+ criteria), and add
   them to the shortlist/application tracker table with Remote/visa
   checked.
5. Outreach ladder, concrete: maintain in the weekly file a table of
   5-8 named people (hiring managers/engineers at T1/T2 targets).
   Ladder per person: touch 1 = substantive comment on their content;
   touch 2 = second comment or connect request with one-line context;
   touch 3 = DM referencing shared thread + one specific ask. One
   touch per person per week max. DM only at touch 3, only after
   profile rewrite is live. Assign this week's touches to specific
   days' engagement slots.
6. Agree next week's tasks interactively, then write
   job-search/weekly/<ISO-week>.md:

   # Week <ISO-week> (<date range>)

   Phase: <1|2|3>

   ## Targets

   - Applications: <n>
   - Outreach touches: <n>
   - Posts: <n>
   - Practice sessions: <n>

   ## Funnel (cumulative)

   - Applies: <n> | Screens: <n> | Loops: <n> | Offers: <n>

   ## Outreach ladder

   - <name> | <company> | touch <1|2|3> planned | <day>

   ## Day plans

   ### <Day date>
   - [ ] MVD: apply to <company> + engage (3 targets)
   - [ ] <block>

   (every day starts with the MVD line; deep work second;
   shortlist/research only as capped 20-min timeboxes)

7. If content/ideas.md has fewer than 4 unchecked ideas, run a
   story-mining top-up.
8. Close with: the week's single most important outcome, and next
   Sunday's expected funnel numbers if the week goes to plan.
