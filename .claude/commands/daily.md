Run the daily job-search ritual. The user arrives with a blank mind -
assign tasks, be specific, leave zero decisions to them. Get momentum
started; on low-energy days shrink the day, never cancel it.

0. URGENT MODE: read job-search/URGENT.md first. Run
   `job-search/scripts/block-timer.sh day` and state day number and
   time elapsed. Use the day's block template from the weekly file.
   Start each block with `block-timer.sh start "<block>" <minutes>`,
   check mid-block, `done` at the end. A block 25%+ over budget gets
   cut - say so and move on. Every close states applications this week
   vs target and runway pressure plainly.
1. Read job-search/strategy.md, the current ISO-week file in
   job-search/weekly/, and the last 5 entries plus weak-areas list in
   job-search/practice/log.md. If the weekly file is missing, offer
   /weekly first.
2. TASK #1 EVERY DAY IS THE MVD BLOCK, before anything else:
   - 1 application: pick it yourself - next unapplied company from the
     shortlist (respect tier order T2/T3 first weeks 1-2), name the
     company, find/name a live posting if known, state which CV
     version, and update the application tracker table. The user should
     only execute.
   - 15 min engagement: name 3 specific targets - posts or people at
     target companies (prefer hiring managers/engineers at T1/T2 from
     the outreach ladder). Substantive comments only.
   - Check the application tracker table for applied roles with a
     drafted or pending email. Nudge the user to send
     the oldest pending message every day until they explicitly confirm
     it was sent.
   - Once MVD is done, the day counts. Everything after is upside.
3. Assemble the rest of the day up to the budget (3h default):
   - One practice session (45-60 min): choose type from ranked
     rotation - live weak areas first, then least recently practiced.
     Coding max 2x/week. Announce type AND topic - no choices.
   - Remaining blocks from the weekly plan in priority order.
   - Shortlisting/company research is NEVER a blocker and NEVER
     before the MVD apply. Cap it at one 20-min timebox per day, only
     if the unapplied queue is below 10.
   - If today is Friday: follow-up sweep - application tracker rows with
     Status applied, Applied > 7 days ago, and Last touch > 7 days: one
     nudge task each.
   - Outreach is not complete while a pending hiring-manager message
     exists. Name the company and say: "Send the [company] message today."
4. Low-motivation protocol: if the user signals low energy, resistance,
   or says "not today" - do not push the full plan. Assign MVD only,
   frame it as a 30-minute day, and offer one optional light task
   (engagement, a follow-up, 20-min k8s video). Streak intact beats
   plan complete. Reshuffle skipped blocks into the week silently.
5. Deliver tasks: if Notion MCP tools are available, add today's tasks
   to the Notion daily todo and confirm. Otherwise print a markdown
   checklist for manual paste.
6. Start executing immediately: MVD apply first - open the shortlist
   tracker, confirm the posting, tick it off. Then run the practice
   session: real interview pacing, one question at a time, full
   out-loud answers, score against the take-home rubric where
   applicable.
7. After practice, append to job-search/practice/log.md (date, type,
   topic, score 1-5, weak areas, next) and update weak areas.
8. Close: what remains today, funnel status one-liner (applies this
   week vs target), any overdue items. If behind target, say so
   plainly and adjust tomorrow's load.
