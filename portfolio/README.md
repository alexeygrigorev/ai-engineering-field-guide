# Portfolio

Choose, plan, build, and present AI engineering portfolio projects you can finish and discuss in interviews.

Start from a real domain, real companies, and real problems. Then choose the technology that fits.

Use this progression:

1. Learn the project types
2. Pick a project
3. Start the project
4. Polish the project
5. Present and discuss the project
6. Avoid common mistakes
7. Study worked project-idea examples

For AI engineering, a project should show more than a prompt or notebook demo.

Useful signals:

- a real user and problem
- realistic inputs
- clear output
- tests
- evaluation
- logging or monitoring
- reproducible setup
- README with decisions and trade-offs

The project bar is grounded in [AI Engineering Buildcamp: From RAG to Agents](https://maven.com/alexey-grigorev/from-rag-to-agents). The Buildcamp projects start with problem selection and a proof of concept. Then they add tests, evaluation, monitoring, and deployment.
